# PadMapper（仮称）

Steam 入力の「入力まわり」だけを切り出した、Windows 10/11 用の常駐ソフトです。
コントローラー（主な対象：Flydigi Vader 4 Pro、DInput モード）の入力を読み取り、キーボード・マウスの入力に変換します。

- 仮想コントローラーは出力しません。コントローラーはゲームからそのまま見え、本ソフトは並行して読み取ってキー・マウス入力を**追加で**送ります
- ViGEmBus・HidHide・Steam などの外部ドライバーやツールは不要です

## ダウンロード
最新のビルド：https://github.com/peykich-design/Application/releases/download/padmapper-latest/PadMapper.exe

.NET のインストールは不要です（exe 1 つ）。初回は Windows の SmartScreen の警告が出ることがあります（「詳細情報」→「実行」）。

## 使い始める
1. Vader 4 Pro を DInput モード（青 LED）で接続します。Flydigi Space Station の本体ジャイロモードはオフにしてください
2. `PadMapper.exe` を起動します
3. 「ホーム」でコントローラーが「接続」になっているか確認します。ならない場合は「診断」でデバイスを確認します
4. 「設定」→「ログオン時に起動」をオンにします（UAC の確認はこのときだけ）。以降は管理者として自動で起動し、管理者権限のアプリやゲームにも入力を送れます

## 主な機能
- **プロファイル**：デスクトップ型（スティック→マウスなどフル機能）とゲーム型（パススルー：ゲームに届く入力はそのまま、追加の出力だけ）
- **割り当て**：コントローラー図でボタン（背面 M1〜M4、C/Z を含む）をクリックして編集。押下・離す・短押し・長押し・ダブルタップ・同時押し・モードシフト。割り当て先はキー・マウスボタン・スクロール・マウス移動・マクロ・プロファイル切替など
- **ジャイロ → マウス**：感度（縦横別）・デッドゾーン・スムージング・加速カーブ・有効化条件（常時／押している間／トグル）・静止時の自動ドリフト補正・リアルタイム表示
- **アプリごとの自動切り替え**：前面のアプリ（exe 名・タイトル・パス）でプロファイルを切り替え。「いまのアプリに紐づける」ボタン
- **オーバーレイ**：背面ボタン M4 の長押しでメニュー。コントローラーだけでプロファイル切替・感度変更・ジャイロ ON/OFF・一時停止
- **診断**：HID デバイス一覧、生レポートの HEX ダンプと差分、ボタンを押して位置を覚えさせるウィザード
- 一時停止（緊急停止）ホットキー（既定 `Ctrl+Alt+Shift+F12`）、タスクトレイ常駐、日本語/英語、ダーク/ライト

設定は `%APPDATA%\PadMapper\` に JSON で保存されます（自動で 5 世代バックアップ）。

## 既知の制限
- UAC の確認画面・ロック画面などのセキュアデスクトップには入力を送れません
- 排他フルスクリーンのゲームの上にはオーバーレイを表示できません（ボーダーレスなら可）
- アンチチート付きのゲームでは、ソフトからの入力がブロックされる場合があります
- ゲーム型では、割り当てたボタンの元の入力もゲームに届きます（二重入力）。ゲームで使っていないボタンに割り当ててください
- DInput モードのままでゲームがパッドを認識するかはゲーム次第です。認識しない場合は、そのゲームだけ XInput モードにするなどで対応してください
- 他のコントローラー（DualSense、DS4、Switch Pro、XInput）は後のフェーズです。診断のウィザードで定義を作れば読み取りはできます
