# Flydigi Vader 4 Pro レポート解析結果

> **状態：実機未検証。** 下の表は SDL のソース（`src/joystick/hidapi/SDL_hidapi_flydigi.c` の V1 プロトコル）を読んで作ったものです。
> 実機で確かめたら、PadMapper の「診断」→「割り当てウィザード」で取り直し、「Markdown を書き出す」の結果でこのファイルを置き換えてください。
> 組み込み定義は `src/PadMapper.Core/Devices/BuiltInDevices.cs`。

## デバイス
- VID / PID：`0x04B4` / `0x2412`（SDL の `USB_VENDOR_FLYDIGI_V1` / `USB_PRODUCT_FLYDIGI_V1_GAMEPAD`）。有線・ドングル・Bluetooth で違う可能性あり（未確認）
- SDL は **インターフェース 2** の独自プロトコルを使っている（標準の HID ゲームパッドとは別のコレクション）
- 入力レポート：32 バイト。先頭が `04 FE`（`[0]` がレポート ID 0x04、`[1]` が 0xFE）
- 初期化：SDL は接続時に情報取得コマンド（出力レポート `05 EC 00 …`）を送っているが、入力のために必要かは未確認。PadMapper は既定では送らない（設定でオンにできる）
- DInput モード（青 LED）で使う。Flydigi Space Station の本体ジャイロ（ジャイロマウス）モードはオフにする

## ジャイロ（deg/s）
16 ビット符号付き（リトルエンディアン）。ヨーは下位・上位バイトが離れている（18 と 20）。
| 軸 | 下位バイト | 上位バイト | 係数 |
|---|---|---|---|
| pitch | 26 | 27 | -72000/32767（≒ -2.197） |
| yaw | 18 | 20 | -72000/32767（≒ -2.197） |
| roll | 29 | 30 | -1200/32767（≒ -0.0366） |

係数は SDL でも「testcontroller で推定した値」とされている。感度は画面で調整するので、向き（符号）と位置が合っていれば実用上は問題ない。

## 特定できなかった項目
実機で未検証のため、全項目が「SDL のソースによる推定」の段階。特に次を実機で確かめる：
- Raw Input でこのレポートが届くか（届かなければ HID の直接読み取りで届くか）
- 初期化コマンドなしでレポートが流れ続けるか
- 背面ボタン M1〜M4 と C/Z のビット位置
- ジャイロの位置と向き
