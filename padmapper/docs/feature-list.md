# Steam入力代替ソフト（仮称 PadMapper）機能リスト 統合版

Steam入力の「入力まわり」だけを切り出した、Windows向け常駐ソフト。
主対象コントローラーは Flydigi Vader 4 Pro（DInputモード）。

## 方針
- **仮想コントローラーは出力しない。** 物理コントローラーはゲームからそのまま見え、本ソフトは並行して読み取り、キーボード/マウス入力を**追加で**送るだけ
- 外部ドライバー・外部ツール（ViGEmBus、HidHide、Steam等）に依存しない
- 仮想パッド出力は将来の拡張。入力取得・変換・出力を分離して、後から追加できる構造にする

## 最重要機能

### 1. UI（Windows 11設定風）
- WPF + WPF-UI（Fluent）。ダーク/ライトはOSに追従
- 左ナビ：ホーム / プロファイル / ジャイロ / アプリ連携 / 診断 / 設定
- コントローラー図上でボタンをクリックして割り当てるビジュアル編集（背面ボタン・C/Zを含む）
- 割り当て先：キーボード / マウスボタン / マウス移動 / スクロール / マクロ / プロファイル切替
- プロファイルのインポート/エクスポート（JSON）

### 2. 安定した常駐とスタートアップ
- タスクトレイ常駐、アイドル時CPUほぼ0%
- 管理者権限：タスクスケジューラの「最上位の特権で実行」でログオン時に自動起動（UACプロンプトなし）
- 管理者権限のアプリ（タスクマネージャー、一部ゲーム）にも入力を送れるよう、本体も昇格して動く
- 二重起動防止、クラッシュ時の自動再起動
- スリープ復帰、コントローラーの抜き差し、Bluetooth再接続後の自動復旧
- ログ出力、診断画面（接続状態、権限状態、レポートのリアルタイム表示）

### 3. ジャイロ
- Vader 4 Proのジャイロを、**マウス移動**に変換
- 感度（X/Y別）、デッドゾーン、スムージング、加速カーブ
- 有効化条件：常時 / ボタン押下中のみ / トグル
- ドリフト補正（静止時の自動キャリブレーション）、軸選択（ヨー/ロール）
- ジャイロ値のリアルタイム可視化
- ※「ジャイロ→スティック出力」は仮想パッドが必要なため対象外（将来拡張）

### 4. アプリごとの自動切り替え
- フォアグラウンドウィンドウ監視（exe名 / ウィンドウタイトル / パス）
- アプリ→プロファイルの紐づけ、デフォルトプロファイル、優先順位
- 切り替え時のトースト通知（任意）、「いまのアプリに紐づける」ボタン

### 5. コントローラーだけで設定変更
- 特定ボタン（背面ボタン等）の長押しで、最前面のオーバーレイメニューを表示
- メニューで：プロファイル切替 / 感度変更 / ジャイロON/OFF / 一時停止
- 設定アプリ本体も十字キー/スティックで操作可能
- 画面上キーボード（後回し可）

## プロファイルの種類
- **デスクトップ型**：スティック→マウス、ボタン→キー等のフル機能
- **ゲーム型（パススルー）**：パッド入力はそのままゲームへ。追加機能のみ有効（ジャイロ→マウス、ボタン→キー/マウス、オーバーレイ）
- アプリ自動切り替えと連動（ゲームexe→ゲーム型、それ以外→デスクトップ型）

## パススルー型でできないこと（仕様）
- パッド内のボタンリマップ（A→B等）
- ゲームに渡るスティック値の加工
- 入力の横取り（押しているのにゲームへ届けない）
- モードシフト中の別レイアウト（ゲームには元の入力が届く）
- 割り当てたボタンの元入力もゲームに届く（二重入力）。ゲームで使っていないボタンに割り当てる運用

## 基本機能
- 入力レイヤー：長押し / 短押し / ダブルタップ / 同時押し / モードシフト（デスクトップ型のみ）
- スティック：マウス化、デッドゾーン、レスポンスカーブ、十字キー化、ラジアルメニュー
- トリガー：アナログ閾値、2段階押し
- 緊急停止ホットキー
- 設定の自動バックアップ、プロファイル破損時のフォールバック
- 日本語/英語UI
- 自動更新は後回し

## 既知の制限
- UACダイアログ、ロック画面、Ctrl+Alt+Delなどのセキュアデスクトップには入力を送れない
- オーバーレイは排他フルスクリーンのゲームには表示できない（ボーダーレスなら可）
- アンチチート付きゲームで、ソフトによる入力送信がブロックされる場合がある
- 他のコントローラー（DualSense、DS4、Switch Pro、XInput）は後のフェーズ

## 未確認事項（実機で検証して判断）
- DInputのままで、普段遊ぶゲームがパッドを認識するか（ゲーム次第）
- Vader 4 Proの背面ボタンが標準HIDレポートに含まれるか、独自レポートか
- ジャイロの値がどのレポートにあるか、初期化コマンドが必要か
- 認識しないゲームがあった場合の運用（そのゲームだけXInputモードに切り替える等）。それでも不足なら仮想パッド出力（ViGEmBusまたはVIIPER）を任意の拡張として検討
